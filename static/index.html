Aviso de protección de datos

Esta aplicación trabaja con datos personales. Mantén el acceso privado, borra archivos temporales cuando termines y conserva solo los certificados necesarios.

Subir Excel o CSV

Columnas obligatorias: NOMBRE, APELLIDOS, DNI, FECHA, ACTIVIDAD, CONTENIDO, ESPECIALIDAD y HORAS.

Plantillas disponibles

Selecciona el diseño que se utilizará para los próximos diplomas.

Activa
El nombre es solo una etiqueta organizativa y no modifica el documento Word.
Vista previa Abrir grande
La plantilla oficial está incluida y siempre estará disponible. En el alojamiento gratuito, las plantillas adicionales subidas pueden borrarse cuando el servidor se reinicie; podrás volver a subirlas desde aquí.

Añadir otra plantilla Word

La plantilla puede usar campos como «NOMBRE» o {{NOMBRE}}. El campo CONTENIDO admite textos largos y saltos de línea.
